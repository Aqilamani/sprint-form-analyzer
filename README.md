# Sprint Form Analyzer

A video-based system for measuring and tracking sprint acceleration
technique using pose estimation. Final Year Project.

## What it does
Turns a fixed-camera sprint video into per-step metrics: trunk angle,
shin angle at touchdown, foot-to-hip distance at touchdown, thigh angle
and kickback.

## Status
Early development. See docs/log.md for progress.

## Stack
FastAPI + OpenCV + MediaPipe (backend), React + TypeScript + Vite (frontend).

## Ethics note
No participant videos or identifiable data are stored in this repository.
